# TPMS Builder - Blender

Procedural tool designed to generate complex geometric lattices and Triply Periodic Minimal Surfaces (Gyroid, Schwarz, BCC) optimized for 3D printing.

## Features
- **Procedural Generation:** Automatic surface mapping.
- **Multi-software Support:** Compatible with Blender.
- **Export Ready:** Clean 100% manifold meshes for additive manufacturing.
